# 波ダッシュバスター GitHub Pages用ファイル

このフォルダ内のファイルを、GitHub Pagesで公開しているリポジトリのルートに配置してください。

## 含まれるファイル

- `index.html`
- `favicon.ico`
- `favicon.svg`
- `favicon-16x16.png`
- `favicon-32x32.png`
- `favicon-48x48.png`
- `apple-touch-icon.png`
- `android-chrome-192x192.png`
- `android-chrome-512x512.png`
- `app-icon.png`
- `site.webmanifest`

## 配置方法

すべて同じ階層に置く前提です。  
`index.html` 内の favicon / app icon 参照も同階層指定になっています。
